# med-tracker-ib
tracking app for medicines to be taken, IB coursework

can register, edit, and delete medicines
Send notifications to your email
see forecast of medicines to take
upload photos of the medicine

interactive GUI developed from WindowBuilder in EclipseIDE
Used SQLite for databasing, development on EclipseIDE
